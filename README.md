# Pet Shop Miau

Site institucional e catálogo independente do Pet Shop Miau, em João Pessoa–PB.

## Destaques

- Experiência narrativa com animações controladas pela rolagem
- Catálogo organizado com produtos e categorias
- Design responsivo para celular e desktop
- Contato, endereço, avaliações e chamadas para ação

## Publicação

O projeto é estático e usa a pasta `dist` como saída de produção. O arquivo `vercel.json` já está configurado para publicação na Vercel.
